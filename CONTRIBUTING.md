# Contributing to Bastion

Bastion is in the planning phase. Right now the most useful contributions are feedback on the docs.

## How to help

- Review the [docs](docs/) and open issues for gaps, mistakes, or better ideas
- Weigh in on the [open questions](docs/13-open-questions.md)
- Suggest scan engines, feeds, or compliance content worth supporting
- Propose test targets for the benchmark lab

## Ground rules

- Bastion must only be used against systems you own or are authorized to test.
- Do not submit exploit code or destructive checks. Verification checks must be safe and non-destructive.
- Keep docs factual; mark estimates and assumptions clearly.

## Process

1. Open an issue to discuss significant changes
2. Branch from `main`, make focused commits
3. Open a pull request with a clear description
