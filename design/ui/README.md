# UI design

First-pass screens from [docs/10-ui-concept.md](../../docs/10-ui-concept.md): Home, Results (action plan), Finding detail.

| File | Screen |
|---|---|
| `Main.dc.html` | Home |
| `Results.dc.html` | Results: action plan |
| `Finding.dc.html` | Finding detail |
| `canvas.json` | Canvas layout (artboard positions and order) |

The files are Claude design-canvas artboards (Design Component pages). Each is plain HTML and CSS, so the markup can be edited directly in this repo.

All numbers, hosts and counts are sample data. `[VERSION]` and `[DATE]` are placeholders.

Not designed yet: live scan view, attack-path graph, compare scans, reports, settings, dark theme, click-through between screens.
