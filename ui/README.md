# UI

First-pass UI for the screens in [docs/10-ui-concept.md](../docs/10-ui-concept.md): Home, Results (action plan), Finding detail.

Plain HTML and CSS, no build step. Open `ui/index.html` in a browser.

| File | Screen |
|---|---|
| `index.html` | Home |
| `results.html` | Results: action plan |
| `finding.html` | Finding detail |
| `styles.css` | Shared styles |

All numbers, hosts and counts are sample data. `[VERSION]` and `[DATE]` are placeholders.

Working: navigation between the three screens. Not working yet: tabs, filters, Copy, Re-test and the AI panel.

Not built yet: live scan view, attack-path graph, compare scans, reports, settings, dark theme.
